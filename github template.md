## iHeater Standalone Firmware v0.4.1

This release synchronizes the latest firmware changes with the `main` branch after the previous incorrect `v0.4.0` release state.

### Changed
- Synchronized the current firmware state into `main`
- Updated firmware package naming for cleaner release files
- Removed duplicate board revision suffix from generated `.bin` filenames

### Added
- On-device trigger temperature programming via the MODE button:
- trigger ON temperature
- trigger OFF temperature

### Notes
- This release is recommended as an update from the previous `v0.4.0` release
- Firmware filenames are now shorter and clearer
