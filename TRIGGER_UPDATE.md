# Обновление логики триггера iHeater

## Назначение

Автоматическое включение/выключение грелки iHeater по температуре стола 3D-принтера.

---

## Физический процесс

```
Температура стола (°C)
    ^
 90 |         ┌────────────────┐ Печать
 85 |        /                  \
 80 |-------/--------------------\-------- TRIGGER_OFF_TEMP
 75 |------/----------------------\------- TRIGGER_ON_TEMP
 50 |     /                        \
 25 |____/                          \____
    └─────────────────────────────────────> Время
         Нагрев    Печать    Остывание
```

**Сценарий:**
1. Принтер начинает печать, стол нагревается от 25°C
2. При достижении 75°C (TRIGGER_ON_TEMP) —  iHeater включается
3. Стол достигает 85°C, печать идёт,  iHeater работает
4. Печать завершена, стол выключен, начинает остывать
5. При 80°C (TRIGGER_OFF_TEMP) — iHeater выключается
6. Стол остывает до комнатной температуры

---

## Логика кода (trigger_state_reached)

### Состояние `trigger_state_reached = false` (ожидание нагрева)

```c
if (trigger_temp >= TRIGGER_ON_TEMP && mode == MODE_0)
{
    trigger_heater_enabled = true;
    mode = TRIGGER_MODE;  // Грелка включилась
}

if (trigger_heater_enabled && mode != MODE_0 && trigger_temp > TRIGGER_OFF_TEMP)
{
    trigger_state_reached = true;  // Стол достиг рабочей температуры
}
```

### Состояние `trigger_state_reached = true` (отслеживание остывания)

```c
if (trigger_temp <= TRIGGER_OFF_TEMP && mode != MODE_0)
{
    mode = MODE_0;
    trigger_heater_enabled = false;  // Грелка выключилась
}

if (mode == MODE_0 && trigger_temp <= TRIGGER_ON_TEMP)
{
    trigger_state_reached = false;  // Готов к новому циклу
}
```

## Калибровка температур триггера

### Вход в режим калибровки

**MODE_0 + длинное нажатие (>2 сек)** → CALIBRATION_STEP_1

### Шаг 1: Установка TRIGGER_ON_TEMP

- **Индикация**: 1 LED мигает 10Гц
- Нагреть стол до желаемой температуры включения (~75°C)
- **Длинное нажатие** → сохранить, перейти к шагу 2

### Шаг 2: Установка TRIGGER_OFF_TEMP

- **Индикация**: 2 LED мигают 10Гц
- Нагреть стол до желаемой температуры выключения (~80°C)
- **Длинное нажатие** → сохранить в NVS, выход
- **Индикация успеха**: все 3 LED мигают 3 раза

### Отмена калибровки

**Короткое нажатие** на любом шаге → отмена, откат изменений (NVS_Load)

---

## Значения по умолчанию

```c
#define TRIGGER_ON_TEMP  75.0f  // Включить iHeater
#define TRIGGER_OFF_TEMP 80.0f  // Выключить iHeater
```

**Важно**: TRIGGER_ON_TEMP < TRIGGER_OFF_TEMP

---

## Безопасность

- В режиме калибровки  iHeater **выключена** (PWM = 0)
- При отмене калибровки значения **откатываются** из NVS
- Watchdog (IWDG) сбрасывается во время индикации

## Диаграмма состояний

```
                    ┌─────────────────────────────────────┐
                    │                                     │
                    ▼                                     │
┌─────────┐  long  ┌───────────────────┐  long  ┌───────────────────┐
│  MODE_0 │ ────── │ CALIBRATION_STEP_1│ ────── │ CALIBRATION_STEP_2│
└─────────┘        │    (1 LED 10Hz)   │        │    (2 LED 10Hz)   │
     ▲             └───────────────────┘        └───────────────────┘
     │                      │                           │
     │    short (отмена)    │     short (отмена)        │ long (сохранить)
     └──────────────────────┴───────────────────────────┘
                                                        │
                                              ┌─────────▼─────────┐
                                              │  NVS_Save()       │
                                              │  3 LED x 3 раза   │
                                              │  → MODE_0         │
                                              └───────────────────┘
```
